# AgroVision — From Space Data to Farm Recovery Decisions
**NASA Space Apps Challenge 2026 | Team Innovatrix | West Bengal, India**

## Overview
AgroVision is an agricultural decision-support platform designed for farmers, field teams, and researchers in West Bengal. It connects NASA Earth observation data (NASA POWER, GPM IMERG, SMAP, Landsat/HLS, MODIS) with local farming knowledge to assess climate risks, track seasonal conditions, and plan sustainable annual crop rotations.

## Quick Start (Frontend)
1. Navigate to frontend:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
